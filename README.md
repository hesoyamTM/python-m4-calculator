# Калькулятор M4

Мощный калькулятор с поддержкой пользовательских функций, переменных и сложных математических выражений.

## 🧮 Базовые операции

- Арифметические: `+`, `-`, `*`, `/` , `//` (целочисленное деление), `%` (остаток от деления), `**` (возведение в степень)
- Математические функции: `sqrt(x)`, `abs(x)`, `pow(x, y)`, `min(...)`, `max(...)`
- Поддержка скобок: сложные вложенные выражения

## 📊 Переменные

- Создание: `let <variable> = <expression>`
- Изменение: `<variable> = <expression>`
- Использование: в любых выражениях

## 🎯 Пользовательские функции

- Создание: `fn <function>(<arg1>, <arg2>, ...) -> <expression>`
- Рекурсивные вызовы: функции могут вызывать другие функции
- Множественные аргументы: от 1 до N аргументов

## Примеры использования

### Работа с переменными

```bash

# Создание переменных
let x = 10
let y = (5 + 3) * 2

# Использование в выражениях
x + y * 2
# Результат: 42

# Изменение переменных
x = 20
y = x / 4
```

### Создание функций

```bash

# Простая функция
fn square(x) -> x ** 2
square(5)  # Результат: 25

# Функция с несколькими аргументами
fn hypotenuse(a, b) -> sqrt(a**2 + b**2)
hypotenuse(3, 4)  # Результат: 5.0

# Функция с использованием других функций
fn circle_area(r) -> 3.14159 * square(r)
circle_area(5)  # Результат: 78.53975
```

### Комбинированные примеры

```bash
# Создаем переменные и функции
let base = 10
fn power_of_base(exp) -> base ** exp

# Используем вместе
power_of_base(2) + power_of_base(3)
# Результат: 100 + 1000 = 1100

# Изменяем базовую переменную
base = 2
power_of_base(8)  # Результат: 256
```

### Сложные математические выражения

```bash
# Вычисление сложных формул
fn quadratic(a, b, c, x) -> a*x**2 + b*x + c
fn discriminant(a, b, c) -> sqrt(b**2 - 4*a*c)

let a = 1
let b = -5
let c = 6

# Корни квадратного уравнения
(-b + discriminant(a, b, c)) / (2*a)
(-b - discriminant(a, b, c)) / (2*a)
```

## Архитектура

Проект построен по принципам Чистой Архитектуры (Clean Architecture), что обеспечивает разделение ответственности, тестируемость и легкость поддержки.

### Структура проекта

```text
├── src                 # Основная логика программы
│   ├── application     # Сервисный слой
│   │   ├── calculator  # Сервис калькулятора
│   │   └── interfaces  # Интерфейс сервиса
│   ├── delivery        # Слой презентации
│   │   └── cli         # Доступ к прилоежнию через консоль
│   └── domain          # Доменный слой
└── tests               # Тесты
    └── unit            # Юнит-тесты
```

### Слои архитектуры

🎨 Слой презентации (Presentation Layer)
CLI (Command Line Interface) - консольный интерфейс пользователя

Обрабатывает пользовательский ввод и отображает результаты

В бесконечном цикле ждет данные от пользотаеля. По регулярным выражениям определяет тип операции (назначение переменной или функции, вычисление выражения) и выполняет соответствующую операцию

Успешные операции выводит зеленым цветом, а ошибки красным

### ⚙️ Сервисный слой (Application Layer)

- Пробрасывает данные в доменный слой
- Содержит use cases приложения
- Реализует CalculatorService

### 🏗️ Доменный слой (Domain Layer)

Содержит в себе основные сущности всей программы, выролняет всю бизнес-логику

#### Calculator

В себе содержит переменные и функции, которые хранятся в словаре. Может определять новые функции или переменные, переопределять старые и так далее. Когда на вход приходит математическое выражение, сначала все локальные переменные (если вызов идет через функцию) заменяются на их значение, потом глобальные.

#### CalcFunction

В самый последний момент заменяются функции: Находится вхождение через str.find(), далее начиная со открывающей скобки указатель идет слева направо, пока не найдет закрывающую скобку, причем все это время идет подсчет вложенных скобок, чтобы точно определить конец функции. Также парсятся и аргументы функции, чтобы их правильно разделить. После этого подсчитываются аргументы этой же самой функцией, и заменяются на вычисленное значение. В такои виде уже выполняется подсчет функции, и ее результат кладется в стек.

#### Expression

Сам калькулятор представляет их себя стек `Expression`. Вычисляется алгоритмом похожим на сортировочную станцию. Указатель опять проходится по всей строке, добавляет числа и операции в 2 отдельных стека, если текущая операция имеет более низкий приоритет, то прошлые значения в стеке вычисляются, до того момента, пока приоритеты операций не восстановятся. Если на пути встречается скобка, то создается новый элемент в стеке `Expression`, и он будет на самом вверху, пока на появится закрывающая скобка. Под конец выражения, все выражения подсчитаются и выдадут ответ.
